# Flora Ville Golf & Country Club — concept site

A one-page concept redesign for Flora Ville Golf & Country Club, Pathum Thani: a Nick Faldo
parkland course 45 minutes north of Bangkok, with night golf under floodlights.

**Live:** https://mpc0367.github.io/floraville/

The signature piece is "The Round, Dealt": all 18 real holes, photographed from above,
played as a pinned scroll on desktop and as a tap-and-swipe hole viewer on phones, with a
scorecard that fills in as you go. Bilingual, English and Thai.

Built as static HTML, CSS and vanilla JavaScript, with GSAP ScrollTrigger for the desktop
scrub. No build step: the repo is the site.

This is an unofficial concept by [O2 Design Studio](https://o2-designstudio.com/). Course
data, policies and imagery come from the club's own published materials (gathered Aug 2026,
checked Nov 2026). Confirm all details with the club: +66 2-598-2555, LINE @floravillegolf.
